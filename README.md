## Problem Idea

This project explores whether a student's study habits and attendance can be used to predict academic performance. The goal is to understand basic machine learning workflows and data analysis techniques using a small educational dataset.

## Current Dataset Status

A sample student dataset is being used for initial exploration and laboratory activities. Data inspection and basic analysis have been completed. Additional datasets may be added in future stages of the project.

## How to Run the Notebook

1. Clone the repository.
2. Install the required packages listed in `requirements.txt`.
3. Open the notebook located in the `notebooks` folder.
4. Run all cells in Google Colab or Jupyter Notebook.

## Preliminary Results

The current results are preliminary and intended only for learning and experimentation. The project is still under development, and findings may change as additional data and models are tested.
